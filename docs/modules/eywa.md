# Eywa — Central Intelligence

> The neural network that connects all Remin modules.

## Purpose

Eywa is the AI orchestration layer. It coordinates between modules to generate intelligent recommendations.

## Responsibilities

- Aggregate context from all modules (weather, inventory, history)
- Generate daily outfit recommendations
- Provide styling rationale and aesthetic classification
- Learn from user preferences over time
